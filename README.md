# 🎯 Tatocao - Daily Facilitator Scheduler

Una aplicación web moderna y ligera para asignar facilitadores de reuniones Daily de forma aleatoria durante los sprints.

## ✨ Características

- **Configuración de Sprint**: Define la fecha de inicio y duración del sprint (por defecto 2 semanas, de miércoles a miércoles)
- **Gestión de Equipo**: Agrega los miembros de tu equipo fácilmente
- **Control de Disponibilidad**: Marca los días en que cada miembro estará ausente
- **Asignación Inteligente**: Genera asignaciones aleatorias respetando las ausencias
- **Exportar a Teams**: Copia el resultado en un formato amigable para Microsoft Teams

## 🚀 Uso

1. Abre `index.html` en tu navegador web
2. Configura la fecha de inicio del sprint y su duración
3. Agrega los nombres de los miembros del equipo
4. Marca los días en que cada miembro estará ausente
5. Haz clic en "Generar Asignación"
6. Copia el resultado para compartirlo en Teams

## 💻 Tecnología

Aplicación web estática construida con:
- HTML5
- CSS3 (diseño moderno y responsive)
- JavaScript Vanilla (sin dependencias)

## 📋 Requisitos

Solo necesitas un navegador web moderno. No requiere instalación ni servidor.

## 🎨 Características Técnicas

- **Sin dependencias**: No requiere npm, webpack u otras herramientas de build
- **Responsive**: Funciona en dispositivos móviles y escritorio
- **Ligero**: Menos de 20KB en total
- **Moderno**: Interfaz limpia inspirada en Fluent Design
